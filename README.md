# Dharma Media

Системный плагин Joomla 6 для загрузки изображений прямо в поле Media. Поддерживает перетаскивание файлов, выбор с компьютера, вставку из буфера и выбор из штатного медиаменеджера. Кириллица и пробелы сохраняются в именах файлов и подпапок.

## Установка

1. Скачайте ZIP из [релизов](https://github.com/shivayanamahom/dharma-media/releases).
2. Установите его через **Система → Установка → Расширения**.
3. Включите **Система — Dharma Media** в менеджере плагинов. По умолчанию подключены вводное и полное изображения материала и изображение категории.
4. Настройте поля, обработку и каталог загрузки. Joomla получает новые версии через **Система → Обновление → Расширения**.

## Работа с полем

- Нажмите **С компьютера**, перетащите файл в область загрузки или сфокусируйте её и вставьте изображение, например через Ctrl+V или ⌘V. В браузере используйте команду **Копировать изображение**.
- Кнопка **С сервера** открывает медиаменеджер Joomla и его файловые адаптеры. Выбранный там файл используется в исходном виде.
- Поддерживается прямая загрузка статичных JPEG, PNG и WebP. Для остальных форматов доступен медиаменеджер в пределах настроек Joomla.
- Файл появляется в медиаменеджере сразу после загрузки. Сохраните запись, чтобы связать её с изображением. Очистка поля удаляет ссылку из записи, а сам файл остаётся доступен в медиаменеджере.

## Настройки

| Настройка | Поведение |
| --- | --- |
| Где подменять поле | Вводное и полное изображения материала, категории, теги, контакты, баннеры, ленты новостей, пункты меню, редактор материалов на сайте. Дополнительные формы панели управления задаются по точному имени Joomla. |
| Обработка | WebP включён по умолчанию, качество 84, предельные ширина и высота по 2000 пикселей. Пропорции и прозрачность сохраняются. 0 отключает ограничение соответствующей стороны. |
| Папка | Корень выбирается из папок локального адаптера Joomla. По умолчанию используется каталог изображений медиаменеджера. Шаблон по умолчанию — `dharma/{year}/{month}`. |
| Шаблон | Доступны `{year}`, `{month}`, `{day}`, `{author}` (ID сохранённого автора или текущего пользователя для новой записи), `{user}`, `{component}` и `{field}`. Например, `Фото сайта/{year}/{month}/{author}`. |
| Имена | Случайный префикс включён по умолчанию. При его отключении совпавшее имя получает номер, например `Главное фото-2.webp`. |
| Лимит | 12 МиБ по умолчанию. Учитываются более низкие лимиты PHP и медиаменеджера Joomla. |

Требуются PHP 8.3+ и GD с поддержкой используемых форматов. Для автоповорота JPEG по EXIF используется расширение PHP EXIF. Прямая загрузка доступна пользователям с разрешением **Создание** для `com_media`. Отключение плагина возвращает стандартный интерфейс Joomla.

## Сборка релиза

Измените версию в `dharmamedia.xml` и `media/joomla.asset.json`. Запустите `./build.sh`, опубликуйте ZIP из `dist/` в релизе GitHub с тегом `vX.Y.Z` и отправьте обновлённый `updates.xml` в `main`. XML содержит контрольную сумму ZIP.
